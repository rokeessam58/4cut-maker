# 체험학습 네컷 메이커

6개 칸에 사진을 올리면 한 장의 콜라주로 합쳐 저장/제출하는 웹앱입니다. (정적 사이트 + Google Apps Script)

## 1. 드라이브 업로드 설정 (최초 1회, 약 5분)
1. 구글 드라이브에 제출용 폴더를 만들고, 주소창의 `folders/` 뒤 문자열(폴더 ID)을 복사합니다.
2. https://script.google.com → 새 프로젝트 → `apps-script/Code.gs` 내용을 붙여 넣고 `FOLDER_ID`를 수정합니다.
3. 우측 상단 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 후 권한 승인(고급 → 계속)을 하고, 나오는 `…/exec` URL을 복사합니다.
4. `config.js`의 `APPS_SCRIPT_URL`에 그 URL을 붙여 넣습니다.

> 코드를 수정하면 "배포 관리 → 새 버전"으로 다시 배포해야 반영됩니다.

## 2. GitHub Pages 배포
1. 이 폴더를 새 GitHub 저장소에 올립니다.
2. 저장소 **Settings → Pages → Branch: main / (root)** 선택 후 저장.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소>/` 주소로 접속됩니다. 학생들에게 QR로 배포하세요.

## 참고
- 웹앱 URL을 아는 사람은 누구나 제출할 수 있습니다. 학교 밖에 공유하지 마세요.
- 제출이 실패하면 "기기에 저장"으로 PNG를 받아 직접 전달할 수 있습니다.
